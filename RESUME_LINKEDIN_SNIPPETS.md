## Interview Talking Points

When discussing InfraSight in interviews, emphasize:

1. **Full-Stack Ownership**
   > "I built the entire application solo—from the React frontend to the FastAPI backend to the ML pipeline and production deployment."

2. **Production Deployment**
   > "It's not just a demo—it's a live, working application anyone can try at infrasight.netlify.app."

3. **Technical Decisions**
   > "I chose FastAPI for its async support and automatic API documentation. For anomaly detection, I used Z-score analysis because it's interpretable and doesn't require training data."

4. **ML in Production**
   > "I learned that productionizing ML is different from notebooks—you need to balance accuracy with latency and provide configurable parameters for users."

5. **Architecture**
   > "I used a microservices architecture with the frontend on Netlify's CDN, the backend containerized on Render, and a serverless PostgreSQL database on Neon.tech."
