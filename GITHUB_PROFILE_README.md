## 🚀 Featured Project

### 🔍 InfraSight — Cloud Cost Intelligence Platform

A full-stack ML-powered platform for cloud cost analytics, featuring anomaly detection, cost forecasting, and optimization recommendations.

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen?style=flat-square)](https://infrasight.netlify.app/)
[![Source Code](https://img.shields.io/badge/code-GitHub-181717?style=flat-square&logo=github)](https://github.com/aabhiyann/infrasight)
[![API Docs](https://img.shields.io/badge/API-docs-blue?style=flat-square)](https://infrasight-rs1b.onrender.com/docs)

**What it does:**
- 📊 **Forecasts** future cloud costs using Linear Regression with temporal features
- 🚨 **Detects anomalies** in spending patterns using Z-score statistical analysis
- 🔬 **Clusters** services by spending behavior using K-means
- 💡 **Recommends** cost optimization opportunities

**Tech Stack:**  
`React 19` `TypeScript` `FastAPI` `PostgreSQL` `scikit-learn` `Docker` `JWT Auth`

**Architecture:**
```
React + TypeScript (Netlify) → FastAPI + ML (Render) → PostgreSQL (Neon.tech)
```

**Key Highlights:**
- ✅ Built entire full-stack application solo
- ✅ Production deployment with Docker and CI/CD
- ✅ Async Python with FastAPI + asyncpg
- ✅ Three accessibility themes (dark/light/high-contrast)
- ✅ JWT authentication with role-based access
