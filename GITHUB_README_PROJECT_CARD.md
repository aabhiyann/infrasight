## 🔍 InfraSight - Cloud Cost Intelligence Platform

> ML-powered cloud cost analytics platform with anomaly detection, forecasting, and optimization insights

**🌐 [Live Demo](https://infrasight.netlify.app/)** · **💻 [Source Code](https://github.com/aabhiyann/infrasight)** · **📖 [API Docs](https://infrasight-rs1b.onrender.com/docs)**

### What It Does
- 📊 **Forecasts** future cloud costs with confidence intervals
- 🚨 **Detects anomalies** in spending patterns using Z-score analysis
- 🔬 **Clusters** services by spending behavior using K-means
- 💡 **Recommends** cost optimization opportunities

### Tech Stack

| Frontend | Backend | ML/Data | DevOps |
|----------|---------|---------|--------|
| React 19 | FastAPI | scikit-learn | Docker |
| TypeScript | PostgreSQL | pandas | GitHub Actions |
| Chart.js | SQLAlchemy | NumPy | Netlify/Render |

### Key Features
- ✅ JWT authentication with role-based access
- ✅ Interactive visualizations with Chart.js
- ✅ Dark/Light/High-contrast themes
- ✅ CSV export functionality
- ✅ Async API with Pydantic validation
- ✅ Dockerized deployment

### Architecture
```
React (Netlify) → FastAPI (Render) → PostgreSQL (Neon.tech)
                       ↓
              ML Pipeline (scikit-learn)
              - Anomaly Detection (Z-score)
              - Forecasting (Linear Regression)
              - Clustering (K-means)
```
